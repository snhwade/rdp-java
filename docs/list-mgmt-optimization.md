# 名单管理优化定稿

> 更新：2026-08-23  
> 状态：L1 / LD1 / LS1 / LX1 / LM1 **已实现**

---

## 产品边界

- 平台提供：名单数据维护、命中/筛查能力、引用门禁、导入审计与通用统计。
- **名单本身不决定黑/白处置**；通过/拦截由规则包、决策流引用命中结果后决定。
- **不做**：预置业务处置模板、「建议如何管名单」、具体外部制裁源对接产品（LX2 二期）。

---

## 已确认方案

| ID | 主题 | 结论 |
|----|------|------|
| **L1** | 引用可见 + 变更门禁 | 名单库详情展示被哪些**规则包 / 决策流**引用；删除或停用库时有引用则**阻断** |
| **LD1** | 备注 | 库 / 条目备注补齐，列表靠右展示（对齐其它模块） |
| **LS1** | 筛查与名单打通 | 名称筛查试跑命中后可**跳转名单条目**；文案明确指向名单管理 |
| **LX1** | 外部同步基线 | **预留同步接口** + **导入审计**（来源、批次、条数）；不接具体外部源 |
| **LM1** | 通用统计 | 库级：总条数、启用数、即将失效数等（无业务建议文案） |

## 实现说明

| ID | 落地 |
|----|------|
| **L1** | `ListLibraryReferenceChecker` 扫描 `rule_v2` / `decision_flow` / `decision_flow_version` 中 `libraryCode`/`listLibraryCode`/`listCode`；`GET .../references`；删除/停用阻断 |
| **LD1** | Flyway **V45**：`list_library.remark`、`list_entry.remark`；控制台表单与列表列 |
| **LS1** | 筛查合并 `list_entry`（模糊维度）+ 返回 `matchedEntryId`/`libraryId`；试跑页 Link → `/list-libraries?libraryId=&highlightEntryId=` |
| **LX1** | `POST .../sync` 写 `list_import_audit`（`STUB_RECORDED`）；`GET .../import-audits` |
| **LM1** | 列表/详情统计：total / enabled / expiringSoon（默认 7 日） |

---

## 与其它模块关系

- 决策流 LIST_CHECK / 名称筛查：命中能力已有；LS1 改善排障路径
- 运营与治理 OS1：与 LS1 同源（筛查命中跳转名单）
- 参数管理字段血缘：名单维度字段若走全局字段库，仍受 Q1-B 约束
- 评级模型：本期维持现状，与名单无强制联动
