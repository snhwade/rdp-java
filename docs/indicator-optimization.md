# 指标配置优化定稿

> 更新：2026-08-24  
> 状态：IR1 / ID1 / IS1 / IV1 **已实现**；IM0 / IQ0 本期不做  
> 说明：用户回复含 `D1`，选项表为 **ID1（备注）**，按 ID1 落文档。

---

## 产品边界

- 平台提供：指标分组与图像化定义、上下线、引用门禁、定义回退、累计/读取与通用运行统计。
- **不负责**业务是否采用某指标、阈值如何设定。
- **不做**：业务场景指标模板、「建议该指标是否上线」、替业务写条件；本期也不做多事件聚合产品化（IM0）。

---

## 已确认方案

| ID | 主题 | 结论 |
|----|------|------|
| **IR1** | 引用可见 + 变更门禁 | 详情展示被哪些**规则包 / 决策流**引用；**删除或下线**时有引用则**阻断** |
| **ID1** | 备注 | 强化 `description`/备注，列表靠右展示（对齐其它模块） |
| **IS1** | 运行通用统计 | 分组/指标级：上线数、最近累计时间、读缺失次数等（**无**业务建议文案） |
| **IV1** | 定义回退 | 改定义可**回退上一版快照**（平台能力，非业务建议） |

---
