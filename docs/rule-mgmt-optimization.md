# 规则管理优化定稿

> 更新：2026-08-23  
> 状态：S1 + P2 + L0 **已实现**

---

## 产品边界（硬原则）

- 平台只提供：**规则配置、上线（启用/禁用/回退）、引擎执行**。
- **不负责**业务场景决策，不做「建议发布 / 不建议」类产品结论。
- 是否上线由风控策略师与业务人员基于数据自行校验。

---

## 已确认方案

| ID | 主题 | 结论 |
|----|------|------|
| **S1** | 试运行 | 增加**通用数据统计**（如样本量、PASS/REJECT/REVIEW 分布、命中规则 TopN）；不加建议文案、不做复杂报告产品 |
| **P2** | 发布与回退 | 启用/禁用 + **一键回退到上一启用快照**（平台能力，非业务建议） |
| **L0** | 可读性 | 使用规则已有字段 **`remark`（备注）** 给人看；**不做**条件自动转自然语言摘要 |

### 备注字段说明

- 表：`rule_v2.remark`（VARCHAR 512）
- 用途：人工填写规则意图/适用场景，供协作与复核阅读
- 列表/详情应保证备注可编辑、可展示（若 UI 未突出，实现期一并补齐展示，仍不自动生成）

---

## 明确不做

- 试运行「建议上线」或评分式结论
- 复杂基线对比决策台（通用统计足够）
- 灰度放量产品（本期未选）
- 条件树自动中文摘要（L1）

---

## 实现说明

### S1 试运行通用统计
- 引擎 `DryRunReport` 增加 `decisionDistribution`
- 控制台试运行报告：决策分布 + 命中规则 Top10 +（评分包）总分/区间分布；修正 `ruleHitDistribution` / `bandHitDistribution` 字段绑定

### P2 启用快照与回退
- 表：`rule_package_enabled_snapshot`（V43）
- 每次**启用**规则包写入整包快照（包配置 + 分值区间 + 规则内容/状态）
- API：`GET .../enabled-snapshots`、`POST .../rollback-last-enabled`（需至少两次启用）
- 控制台规则包详情：启用/禁用 +「回退上一启用快照」

### L0 备注
- 列表 API 透出 `remark`；规则表单可编辑；列表备注列靠右（操作列最右）
